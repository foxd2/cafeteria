# cafeteria-web

Sitio web sencillo para la cafetería **Café del Rincón**: muestra el menú, los horarios, la ubicación y los datos de contacto.

Proyecto de la práctica *Control de versiones en un proyecto web* (Programación Web Integral).

## Estructura

```
cafeteria-web/
├── index.html
├── css/
│   └── estilos.css
├── img/
│   └── logo.svg
└── README.md
```

## Cómo verlo

Descarga o clona el repositorio y abre `index.html` en el navegador.

## Equipo

- Integrante 1: estructura HTML
- Integrante 2: estilos CSS

## Flujo de trabajo

Se trabaja con ramas (`rama-menu`, `rama-estilos`), commits con mensajes claros y se integran a `main` mediante Pull Request.
